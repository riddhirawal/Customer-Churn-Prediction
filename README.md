# Customer Churn Prediction

## Problem
Predict which customers are likely to churn.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Steps
- Data Cleaning
- EDA
- Feature Engineering
- Model Building

## Models Used
- Logistic Regression
- Random Forest

## Results
- Random Forest performed better than Logistic Regression

## Key Insights
- Month-to-month contracts increase churn
- High monthly charges increase churn
- Low tenure customers churn more
